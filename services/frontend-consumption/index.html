📐 Wzory obliczeniowe

WOM = A × SOM × ZS
• WOM = opłata mocowa [PLN]
• A = współczynnik klasy K (0.17 / 0.50 / 0.83 / 1.00)
• SOM = stawka opłaty mocowej [PLN/kWh]
• ZS = energia w godz. wybranych [kWh]

Δs = (śr_wybrane / śr_poza - 1) × 100%
• śr_wybrane = ZS / liczba_godzin_wybranych
• śr_poza = ZPS / liczba_godzin_poza
